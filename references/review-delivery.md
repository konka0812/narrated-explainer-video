# 检查与交付

在预览修改、最终导出和按需制作发布素材时阅读。

## 先把反馈转成可验证的改动

| 反馈 | 先检查 | 常用改法 |
| --- | --- | --- |
| “字太小” | 主标题、图注、出处和字幕在观看尺寸下的层级 | 放大并减少字数，裁切放大资料，分步显示 |
| “太空” | 主体占比、分散位置、无效边距 | 扩大主体、收拢布局、调整构图 |
| “动画少” | 句意是否只有字面标签 | 增加对象变化、反馈和结果，而非统一抖动 |
| “重复多” | 是否反复使用同一个静图和进场方式 | 让同一对象演变，补不同解释场景 |
| “太花” | 同时运动的对象、色彩和阅读任务数量 | 减少并发动作、集中焦点、保留观察停顿 |
| “模板感重” | 卡片分栏、伪界面和无关英文是否重复 | 改成与内容相关的场景、机制或资料特写 |
| “没讲清楚” | 因果、条件、尺度或步骤是否缺失 | 补能显示关系的动作，必要时回到内容纠错 |

## 三层检查

### 静帧

至少覆盖开头、文字最多的时刻、截图或图表、关键动作状态、转场交叠和结尾。检查：

- 主体足够大，缩到实际观看尺寸仍知道看哪里。
- 文字不溢出、不缺字，与背景有足够对比。
- 字幕与人物、动作、说明和来源没有冲突。
- 图片清晰，框选命中目标，不遮挡改变含义的上下文。
- 转场期间的极端位置、缩放与透明度没有造成出界或难以读清。
- 单独检查实际首帧与末帧：避免非预期的空白、闪烁、模糊和残留。若平台或用户将首帧用作封面，单独检查其缩略图效果；有意的淡入淡出与结尾停留可以保留，不要求末帧必须发生变化。
- 排查常见缺陷：卡片或角色压住文字、关键内容被字幕遮挡、透明边缘在不同背景上出现光晕、蒙版改变素材色彩，以及画面与字幕同时重复大段文字造成阅读负担。

只检查场景中点可能漏掉短暂重叠。需要时查看动作开始、最大幅度和结束帧。

### 连续播放

优先完整播放最终预览或成片，听口播并看字幕和动作。注意语句起止、长停顿、镜头重复、节奏过密、动作提前或滞后、转场残留、音轨断裂和突然结束。

完成局部修改后，回看该时段的前后衔接；更换音频、字幕或全局时间设置时，需要覆盖全部受影响范围。

若环境只允许取帧或无法听音，记录限制和实际检查范围，交付可播放预览，不声称已完成整片动态或听音验收。

### 文件

确认输出存在且与当前版本一致，检查分辨率、帧率、时长、音轨与编码。可用：

```sh
ffprobe -v error -show_format -show_streams -of json "/project/output/final.mp4"
ffmpeg -v error -i "/project/output/final.mp4" -f null -
```

文件可解码不证明画面优秀或音画同步。工程检查也只证明它对应的技术条件，不能代替播放。

## 按需制作发布素材

封面比例按发布需求，不能一律指定 3:4。先提炼本片最值得点开的一个问题、反差或收益，再设计简短标题和一个明确主体。缩略图下要清楚，文字避开平台裁切与遮挡。

画面与标题可以一并生图；完成后逐字检查错字、字形、标点和排列，必要时修正或改用可编辑文字。封面延续视频的视觉语言，不必截图硬裁。避免夸大视频中没有证据支持的结论。

发布文案保存在独立文件：推荐标题、少量备选、正文和适量话题标签。正文引出问题、说明观看价值，可留一个有讨论空间的问题，不必逐句复制口播。只准备素材不会自动授权发帖。

## 交付记录

按实际完成情况简要记录：

```text
最终输入：音频 / 字幕版本
视频：文件位置、画幅、分辨率、帧率、时长
工程：入口 / 组合 ID、素材位置
检查：看过的静帧与播放范围、文件检查结果
限制：未检查部分或待处理问题，没有则不杜撰
发布素材：仅列实际制作的封面和文案
```

保留可编辑依赖，不把旧导出和原始素材混为一谈。收到清理请求后先识别最终版、仍被引用的素材和共享工程，再按用户授权清理。
